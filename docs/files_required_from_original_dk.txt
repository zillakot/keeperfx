Original Dungeon Keeper files required by KeeperFX
-------------------------------------------------

Copy these 14 files into a complete KeeperFX installation, preserving the
relative paths below. The source can be an original CD or a supported digital
installation. The native Mac engine uses the data files, not the Windows EXE.

For edition-specific extraction instructions, see:
https://keeperfx.net/wiki/launcher-application
